# TreeWise - Interactive Tree Learning Platform

TreeWise is an interactive web platform built for studying and visualizing tree data structures and algorithms (Binary Search Tree, Inorder, Preorder, Postorder, and Level Order traversals).

## Features
- Real-time Binary Search Tree insertion, deletion, and searching
- Draggable and movable nodes on an interactive SVG canvas
- Step-by-step traversal animations with Prev/Next controls
- Preloaded tree examples (Balanced, Classic, Dense, Skewed)
- Mobile-friendly responsive user interface
- Study notes module with quick-insert templates

## How to Run
1. Open `index.html` directly in any web browser.
2. Alternatively, run with VS Code Live Server or python:
   ```bash
   python -m http.server 8000
   ```
